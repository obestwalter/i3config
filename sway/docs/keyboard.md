# Keyboard

* Layout: `input type:keyboard { xkb_layout de }` in `config.d/2-input-output.conf`.
  The bindings use German key names (`numbersign`, `udiaeresis`, `asciicircum`), these are unchanged.
* Find key names with `wev` (replaces `xev`).
* List bindings: `bin/sway-show-bindings.sh`.
* `$win` is `Mod4`, `$alt` is `Mod1` (see `0-basic-setup.conf`).
